# Bundled font licenses

The fonts in `src/main/res/font/` are redistributed under the SIL Open Font License 1.1 (OFL).

| File | Family | Source | License |
|------|--------|--------|---------|
| `fraunces_variable.ttf` | Fraunces (variable: SOFT, WONK, opsz, wght) | https://github.com/google/fonts/tree/main/ofl/fraunces | OFL 1.1 |
| `inter_variable.ttf` | Inter (variable: opsz, wght) | https://github.com/google/fonts/tree/main/ofl/inter | OFL 1.1 |

The full OFL 1.1 text is available at https://openfontlicense.org and in each source repository's `OFL.txt`.
Both families are used as variable fonts; weights are selected at runtime via `FontVariation` in
`theme/Type.kt`.
